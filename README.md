# 🎃 404 Network – Trick or Commit 👻

Welcome to **Trick or Commit**, a Halloween-themed GitHub workshop hosted by 404 Network at UW–Green Bay!

## 🎯 Your Mission

Learn the basics of Git and GitHub by contributing to this repository.

### Step 1: Clone the Repository
Clone this repository to your computer using GitHub Desktop or Git CLI.

### Step 2: Create a Branch
Create a new branch using your name.

Example: `name-halloween`

### Step 3: Make Changes
Open `halloween-messages.txt` and add your name along with a Halloween-themed message. Then add a new file

Example:
`name - 404: Costume Not Found 👻`

### Step 4: Commit Your Changes
Stage your changes and create a commit with a descriptive message.

Example: `Added name Halloween message`

### Step 5: Push Your Changes
Push your branch to GitHub.

### Step 6: Create a Pull Request
Open a pull request to merge your changes into the main branch.

## 👻 The Trick

Something unexpected might happen during the challenge!

Can you troubleshoot the problem using what you've learned?

## 🍬 The Treat

Complete the challenge and earn some candy!
